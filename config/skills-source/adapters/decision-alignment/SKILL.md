# Decision Alignment Adapter

Use this skill before committing to a non-trivial direction.

## Process

1. Restate the goal and user intent.
2. List known facts and constraints.
3. Identify missing facts that materially affect the decision.
4. If needed, use best-practice research before recommending.
5. Compare viable options with costs, risks, and fit.
6. Recommend one path and explain rejected paths.
7. Define acceptance criteria.
8. Ask for confirmation before semantic writes.

## Output Contract

- Goal understanding
- Known facts
- Constraints
- Options
- Tradeoffs
- Recommendation
- Rejected options and reasons
- Acceptance criteria
- Confirmation points
