# Task Routing

- Tiny edit: inspect nearby code, patch, run focused check.
- Bug fix: use `debugging`, reproduce or locate failure, add regression coverage when practical.
- Feature: clarify contract, test first when feasible, implement narrowly.
- Refactor: preserve behavior, keep diff mechanical, verify affected tests.
- UI: inspect existing design system, implement usable flow, verify responsive layout where feasible.
- Config/tooling: document command changes and avoid broad migrations.
- Formal delivery: use `pr-workflow` when branch/PR/CI/review exists.
